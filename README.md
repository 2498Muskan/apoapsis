# 🌌 APOAPSIS — The Point Farthest From Home

APOAPSIS is an interactive educational website that takes users on an immersive journey through all eight planets of our solar system.

The website combines real planetary information with modern web animations, interactive navigation, visual effects, and a space-inspired interface to make learning about the solar system more engaging.

## 🚀 Features

- 🌍 Interactive exploration of all 8 planets
- 🪐 Detailed planetary information
- 📊 Planet statistics and comparisons
- ✨ Animated starfield and shooting stars
- 🎬 Smooth scroll-based animations
- 🖱️ Custom interactive cursor
- 🎵 Synthesized ambient space sound
- ⏱️ Mission time and Earth UTC clock
- 📱 Responsive design for mobile devices
- 🔭 Interactive planet navigation
- 📋 Planet comparison table
- ⚡ GSAP and ScrollTrigger animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- HTML Canvas
- Web Audio API
- Google Fonts
- Wikimedia Commons images

## 🌠 Project Concept

The name **APOAPSIS** refers to the point in an orbit that is farthest from the central body. The website uses this concept as a theme for an educational journey through the solar system.

Users can start from Earth and travel through Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune while discovering facts, statistics, and unique characteristics of each planet.

## 🎯 Purpose

The goal of APOAPSIS is to present astronomy and planetary science in an interactive and visually engaging way rather than through traditional static educational content.
